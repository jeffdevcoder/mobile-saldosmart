## 📱 Sobre


O **SaldoSmart** é um projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Mobile. O objetivo do aplicativo é facilitar a gestão e o controle de finanças pessoais, permitindo aos usuários acompanhar suas receitas e despesas de forma intuitiva.

O backend da aplicação encontra-se hospedado na nuvem (AWS), provendo uma API Restful conectada a um banco de dados relacional, que é consumida pelo aplicativo mobile.

**🔗 Acesso à API / Deploy AWS:** [http://3.83.233.59/](http://3.83.233.59/)

## 🚀 Tecnologias Utilizadas

### Front-end
* **React Native** - Construção das interfaces e componentes nativos.
* **Axios** - Integração e consumo da API.
* **React Navigation** - Roteamento e navegação entre telas.

### Back-end & Infraestrutura
* **Node.js** - Construção da API Restful.
* **PostgreSQL** - Banco de dados relacional para armazenamento das finanças e usuários.
* **AWS (Amazon Web Services)** - Hospedagem da aplicação em servidor nuvem (EC2).
